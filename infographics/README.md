# Инфографика

## Стратегия реформирования пенсионной системы Республики Узбекистан (2027–2040)

Перевод исходной инфографики с узбекского языка на русский. Структура, состав
разделов, порядок блоков и все числовые значения сохранены без изменений;
переработаны только типографика, сетка и оформление.

| Файл | Назначение |
| --- | --- |
| `pension-strategy-ru.src.html` | Исходник для правок (шрифты — плейсхолдеры) |
| `pension-strategy-ru.html` | Готовый автономный файл, открывается без интернета |
| `pension-strategy-ru.pdf` | Одностраничный PDF, 338 × 391 мм |

### Сборка

```bash
python3 infographics/build.py     # вшивает шрифты → *.html
cd app && npm run pdf             # печатает *.html → *.pdf
```

`build.py` встраивает IBM Plex Sans (кириллица + латиница) как data-URI, поэтому
готовый HTML не обращается к внешним ресурсам и выглядит одинаково на любой
машине. Шрифты попадают и в PDF (встроенные подмножества Type 3), так что текст
не подменяется при открытии на другом компьютере.

### Замечание к исходнику

В оригинальной инфографике у III этапа указан период **2028–2029 годы**, тогда как
на шкале внизу III этап расположен между **2035** и **2040**. Это расхождение есть
в исходном материале; при переводе оно сохранено без правок.

### Оформление

Материал неофициальный. Государственная символика не воспроизводится — вместо
эмблемы использован нейтральный типографский акцент.
